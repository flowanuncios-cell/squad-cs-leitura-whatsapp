# 06 — Manual de Treinamento Flowformance

> Este é o documento que o gestor novo lê **no primeiro dia**.
> Toda a complexidade da Flowformance cabe embaixo de **8 verbos**.

---

## 1. A linguagem oficial: os 8 verbos

```
RECEBER → ACESSAR → ENTENDER → INTEGRAR → CONSTRUIR → PUBLICAR → MEDIR → OTIMIZAR
```

| Verbo | O que significa | Fase |
|---|---|---|
| **RECEBER** | Grupo, agenda, Trello, planilha, responsáveis | 1 |
| **ACESSAR** | Meta, Google, Instagram, site, GMN, ferramentas | 3 |
| **ENTENDER** | Produto, objetivo, público, verba, oferta, funil | 2 |
| **INTEGRAR** | Pixel, tags, eventos, CRM, Make, tracking | 3 |
| **CONSTRUIR** | Campanha, públicos, criativos, copy, orçamento | 4 |
| **PUBLICAR** | Checklist, saldo, tracking, campanha e documentação | 4 |
| **MEDIR** | Stract, relatórios, WhatsApp, CRM, qualidade dos leads | 5 |
| **OTIMIZAR** | Campanha, criativos, verba, funil, OS, reuniões, novos ciclos | 5 e 6 |

> **Nota de ordem:** na prática, ACESSAR e ENTENDER correm em paralelo. Pedimos
> os acessos logo no D1 (porque o cliente demora) enquanto entendemos o negócio
> no briefing. A sequência dos verbos é a lógica de dependência, não o calendário.
> O calendário é o dos Gates.

### Como usar os verbos no dia a dia

Em toda conversa interna — reunião, grupo, card — a pergunta é sempre a mesma:

> **"Em que verbo esse cliente está?"**

Se a resposta demora, o card está desatualizado. Se duas pessoas respondem coisas
diferentes, o Gate não foi formalizado.

## 2. As três perguntas que o gestor deve saber responder sozinho

| Pergunta | Onde está a resposta |
|---|---|
| "Em qual fase este cliente está?" | Lista do Trello + Gate atual |
| "O que falta para avançar?" | Checklist da fase, item não marcado |
| "Quem está travando e desde quando?" | Registro de bloqueio no card |

Um gestor que responde essas três sem chamar o líder está operando o sistema.

---

## 3. A regra central

> ### Não otimizar apenas o Gerenciador. Otimizar o sistema de aquisição.

O Gerenciador é **uma** etapa de seis. Mexer só nele é como ajustar o volume de
um rádio sem antena.

```
 ANÚNCIO  →  CLIQUE  →  PÁGINA/WHATSAPP  →  LEAD  →  QUALIDADE  →  VENDA
    │           │              │              │          │           │
   CPM         CTR          taxa de        CPL/CPA     % de       receita
  alcance      CPC         conversão      volume    qualificado   ROAS
```

**Toda análise começa na direita e caminha para a esquerda.** Se não há venda,
a pergunta não é "qual criativo trocar" — é "em qual etapa a sequência quebra".

## 4. Tabela de diagnóstico

O gestor novo deve conseguir usar esta tabela sem ajuda:

| Sintoma | Etapa que quebrou | Hipótese mais provável | Primeira ação |
|---|---|---|---|
| CPM alto, pouco alcance | Anúncio | Público estreito, leilão caro, criativo fraco | Ampliar público, testar novo ângulo |
| Alcance ok, **CTR baixo** | Anúncio | Criativo/copy não conversa com o público | Novo ângulo criativo, não só novo formato |
| CTR bom, **poucos chegam na página** | Clique → Página | Página lenta, link errado, experiência mobile ruim | Testar o link com clique real, medir velocidade |
| Chegam na página, **não viram lead** | Página → Lead | Promessa quebrada entre anúncio e página, formulário longo, oferta fraca | Alinhar promessa, reduzir atrito, reforçar prova |
| **Muitos leads, qualidade ruim** | Lead → Qualidade | Promessa genérica demais, segmentação larga, formulário fácil demais | Qualificar já no anúncio, adicionar filtro, revisar oferta |
| Leads bons, **não vira venda** | Qualidade → Venda | Demora no atendimento, script fraco, preço/condição | Medir tempo de resposta, alinhar com quem atende |
| Tudo funcionava e caiu de repente | Qualquer | Saldo, anúncio reprovado, pixel quebrado, fadiga de criativo | Checar entrega, saldo e tracking **antes** de mexer em estratégia |

> **Antes de mexer em qualquer coisa:** confira entrega, saldo e tracking. Metade
> das "quedas de performance" é uma dessas três.

---

## 5. Como otimizar sem se enganar

1. **Escreva a hipótese antes de mexer.** "Acredito que o CPL cai se eu trocar o
   ângulo, porque o CTR está baixo e o público é amplo."
2. **Uma mudança por ciclo.** Duas mudanças juntas = nenhum aprendizado.
3. **Defina a data de avaliação antes.** E não olhe antes dela — a não ser que
   algo esteja quebrado.
4. **Registre o resultado**, inclusive quando a hipótese estava errada. Hipótese
   errada registrada vale mais que acerto não documentado.
5. **Volume mínimo antes de concluir.** Decidir com 3 conversões é adivinhação.

Formato do registro (comentário no card):

```
[OTIMIZAÇÃO] dd/mm
Hipótese: ...
Ação: ...
Avaliar em: dd/mm
Resultado: ...
```

## 6. Os 7 erros que este sistema existe para evitar

| Erro | O que impede |
|---|---|
| Campanha no ar sem tracking | Gate 3 |
| Cliente sem saldo no dia da publicação | Checklist de integração, bloco A/B |
| Criativo descoberto atrasado na véspera | Levantamento no D4 + OS aberta |
| Integração faltando percebida depois de publicar | Gate 3 e Gate 4 |
| Campanha sem documentação (ninguém sabe o que foi testado) | Doc da 1ª Campanha |
| Lead gerado e não atendido | Pergunta obrigatória do Gate 2 |
| "Onboarding concluído" com rotina não funcionando | Gate 6 |

## 7. O que o gestor novo faz nas duas primeiras semanas

| Semana | Foco |
|---|---|
| **Dia 1** | Lê este manual, o [`01`](01-jornada-operacional.md) e o [`02`](02-gates.md) |
| **Dias 2–3** | Acompanha um cliente em cada fase, só observando o board |
| **Semana 1** | Executa a Fase 1 e 2 de um cliente novo, com o líder revisando |
| **Semana 2** | Executa Integração e Ativação com revisão de 4 olhos obrigatória |
| **A partir daí** | Assume clientes com os Gates validados pelo LS |

**Nenhum gestor publica campanha sozinho antes de ter passado por uma revisão de
4 olhos completa (Gate 4) com o líder.**

## 8. Vocabulário que não usamos

| Não diga | Diga |
|---|---|
| "Já pedi o acesso" | "Item 🟡 desde dd/mm, cobrado em dd/mm, dono: ___" |
| "Está quase pronto" | "Faltam os itens X e Y do checklist do D4" |
| "A campanha está ruim" | "O CTR está em X; o gargalo está na etapa Anúncio" |
| "Vou otimizar" | "Hipótese X, ação Y, avaliação em dd/mm" |
| "Onboarding concluído" (no D10) | "Campanha publicada. Onboarding conclui no Gate 6" |
| "O cliente é lento" | "Bloqueio registrado dd/mm, escalado em dd/mm" |
